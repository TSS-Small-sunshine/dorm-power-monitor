欢迎使用 dorm-power-monitor

跟着 6 步向导完成首次配置,预计 3 分钟。

  • 1. 飞书凭证 — 飞书开放平台 App ID / Secret
  • 2. 推送 Webhook — 告警和报表的推送地址
  • 3. 定时计划 — 抓取 cron 表达式 + 时区
  • 4. 数据保留 — 历史保留天数 + 月备份份数
  • 5. Admin 账户 — 创建管理员账号

开始前准备好飞书机器人凭证 + webhook URL。

飞书凭证

填写飞书开放平台的自建应用凭证 (用于调用 tenant_access_token)。

推送 Webhook

dorm-power-monitor 会把告警 / 日报 / 周报 / 月报推送到此 webhook。

允许的 host: *.tssplus.top, localhost

定时抓取计划

5 字段 cron 表达式 (分 时 日 月 周),控制抓取频率。

默认 */30 * * * * = 每 30 分钟一次

数据保留

历史采集记录的保留天数,以及月备份保留份数。

最少 5 天,默认 90
默认 12 份

本步可使用默认值 — 跳过即可。

创建 Admin 账户

这个账户将登录 dashboard 与 admin 后台。

至少 8 字符,包含大小写字母 + 数字 + 特殊字符
